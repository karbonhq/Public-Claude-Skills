## Banned — no client data, no exceptions

The following tiers train on user prompts by default and are explicitly banned for any client data, including tax return information, account numbers, SSNs, financial figures, and identifiable client communications.

- **ChatGPT Free / Plus** (consumer)
- **Claude Free** (consumer)
- **Gemini personal** (consumer)
- **Microsoft Copilot personal / web** (consumer)
- Any general-purpose LLM accessed via a personal account
- Any AI tool whose training-data terms have not been reviewed by [name]

Personal-account use of these tools for non-firm-related personal work is permitted, but no firm or client data may ever be entered.

## Conditional use — meeting transcription

Meeting transcription tools (Fathom, Otter, Fireflies, etc.) are sanctioned for internal meetings and for client meetings where the client has been notified that the meeting is being transcribed and has not objected. For client meetings, transcripts are stored in the firm's PM (e.g., Karbon) and not shared externally.
