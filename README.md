# Karbon Public Claude Skills

A curated public marketplace of Claude Code plugins built by Karbon for accounting professionals.

## What this is
This repository is a Claude Code plugin marketplace. It currently distributes one plugin — **Karbon Plugins** — a growing collection of skills for the work accounting firms actually do. Open to everyone, whatever practice management platform you're on.

## Installation
In Claude Code:

```
/plugin marketplace add karbonhq/public-claude-skills
/plugin install karbon-plugins@karbon-plugins
```

After installing, run `/reload-plugins` and Claude will load the skills automatically when your prompt matches.

## What's a Claude skill?
A skill is a folder with a `SKILL.md` file that tells Claude how to do a specific kind of work. Skills are reusable, composable, and version-controlled. Learn more: [Anthropic's skills documentation](https://www.anthropic.com/news/skills).

## What's inside
- `karbon-plugins` — Karbon's curated skills for accounting firms. Currently in initial scaffolding; skills will be added as they are built and validated.

## Curation
This repo is curated and maintained solely by Karbon. It is public so anyone can read, fork, and install plugins, but it does not accept outside pull requests or issue submissions. If you have feedback or want to flag something, email byron.patrick@karbonhq.com.
